# grill-with-docs

Vendored from [mattpocock/skills](https://github.com/mattpocock/skills)
(`skills/engineering/grill-with-docs`).

Thin user-invoke router that runs a `grilling` session composed with
`domain-modeling` (which this plugin ships adapted to the GLOSSARY.md
convention), so the interview writes glossary terms and ADRs as they
crystallise.

To update:

```bash
npx skills add mattpocock/skills -y --skill grill-with-docs
```
