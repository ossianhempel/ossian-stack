# YouTube idea and manuscript draft

Read this when an existing piece should become a YouTube concept, outline, or spoken script.

## Select the idea

Find the question, demonstration, or tension in the source that can sustain a video. The video may develop one part of the writing, add a real demonstration, or test its claim. It does not need to recite the essay. If several strong concepts exist, show two or three with a one-line viewer payoff and recommend one. When the request includes a manuscript draft, write the strongest supported concept in the same turn. Ask only when the concepts imply different positions that Ossian must choose between.

Package the selected concept with a working title, the audience's question, the answer or payoff, and the source evidence available. A thumbnail or visual premise is useful when it can be shown truthfully; do not make it a mandatory decoration.

## Draft the script

- Write words meant to be spoken. Start at the concrete problem, result, or point of tension. Avoid channel greetings, an essay abstract, and promises to cover topics later.
- Give the viewer the claim early, then earn it through a specific experience, example, live walkthrough, or visible comparison. Each section should change what the viewer understands or can do. A video needs enough substance to justify its length; do not stretch one paragraph into a long script.
- Mark demonstrations, visuals, screen recordings, and B-roll as production cues separate from spoken lines. Say whether an asset exists, needs capture, or is only an idea when that distinction matters.
- Preserve the source's uncertainty. Use `[verify: …]`, `[show: …]`, or `[Ossian to add: …]` for missing evidence or first-person experience. Never turn an inferred scene into a memory in his voice.
- End with the portable decision or lesson and, where relevant, the source's limit. Include a single link or next step only when requested or naturally warranted. No summary monologue or slogan.

Deliver a **first draft**, not a publication-ready claim. For a reviewable draft, include the working title and concept, the full spoken script with concise production cues, and a short list of unresolved factual or filming needs. Estimate run time from the actual spoken text if useful, and label it an estimate.
