# X and TikTok

Read this when the requested derivative is an X post, X thread, TikTok video, or TikTok slideshow. Treat a personal editorial post differently from a product ad. Keep the source's point of view and give a new viewer a complete payoff within this post.

## X

- Find the smallest defensible claim or distinction that stands alone. Open with the claim, a concrete situation, or an earned curiosity gap. Do not introduce the article or say “I wrote about…” unless the relationship to the source is the point.
- Prefer one post for one idea. Use a thread only when the evidence, sequence, or example needs multiple posts; every post should advance the thought. Do not create a thread to fit the whole essay. Check the current platform limit before claiming a draft is ready to paste if length matters.
- Bring one real detail from the source: an actual command, failure, number, choice, or example. Link to the source once only when the user wants a traffic path and the link exists. No “thread 🧵,” “agree?,” or empty engagement question.
- Output the publishable text first. Add a brief source/evidence note only if a claim needs checking.

## TikTok

- For Ossian's own editorial writing, default to a talking-head or simple demonstration script when the user has not chosen a format. Choose a slideshow only when the material is genuinely visual or sequential, or the user asks for one. If a format preference is established in the current request, follow it.
- Open on a recognizable situation, visible result, or strong claim in the first seconds. Do not spend the opening naming the topic, greeting viewers, or referring to the article.
- Give one thought per clip. Build from **opening → concrete example or demonstration → explanation → useful ending**. The ending can state the rule, decision, or limit. Avoid a recap and a forced CTA.
- For video, provide the spoken words and a compact shot/on-screen cue list. Separate a proposed shot from footage known to exist. A screen recording, command output, or before/after must be real before presenting it as captured evidence. Read the spoken text aloud or estimate its duration honestly; tighten lines that only work on paper.
- For a slideshow, provide slide-by-slide on-screen copy and visual purpose, plus a caption only if it adds context. Each slide must move the idea forward. Do not just paste paragraphs onto cards.
- Do not import app-ad patterns or unverified platform performance rules into a personal essay cut. Apply the current `VOICE.md` to spoken language too; contractions and plain verbs matter more than formal narration.

If both channels are requested, make the X text and TikTok script independently useful. A TikTok transcript pasted into X is not a second cut.
